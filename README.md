# 徐州诚泰产品网站

网站：https://protiger.net/

本仓库使用 GitHub Pages 发布静态页面，域名由根目录 `CNAME` 维护。

页面保留左侧分类介绍、右侧配图的结构；移动端自动纵向排列。
产品目录面向客户介绍六大品类的产品范围、应用场景及配套服务，不展示具体采购型号或采购记录。图片位于 `images/catalog/`，为 AI 生成的品类示意图，页面已说明，不代表具体型号实拍。

更新产品时同步核对产品范围、介绍内容及品牌归属。勿将业务台账、合同、价格、客户资料或原始凭证加入仓库。

## 配图说明
